# UI Contract: 学習項目追加モーダル化

**Branch**: 003-item-add-modal  
**Date**: 2026-03-02  
**Spec**: [../spec.md](../spec.md)

## Overview

この契約は「学習項目の追加導線」をモーダルに変更するためのUI仕様を定義する。

## Entry Point

- 一覧領域の右上にボタンを表示する
- ボタン文言: **「新規」**
- ボタン押下で学習項目追加モーダルを開く

## Modal Layout

- モーダル内部に既存の学習項目追加フォーム（タイトル/内容/タグ）を表示する
- モーダル下部に、左に「キャンセル」、右に「追加」ボタンを配置する

## Close Behavior

以下の操作はすべて「キャンセル」と同じ扱い（モーダルを閉じ、入力をクリア）とする:

- 「キャンセル」ボタン
- 背景（オーバーレイ）クリック
- ESC キー

## Submit Behavior

- 「追加」ボタン押下で追加処理を実行する
- 追加処理中は重複送信を防止する（例: 追加ボタン disabled）
- 追加成功: モーダルを閉じ、入力をクリアし、一覧に追加結果が反映される
- 追加失敗: 失敗が分かる表示をモーダル内に出し、モーダルは閉じない

## Error Presentation

- 入力不備（バリデーション）: モーダル内の該当箇所に分かる表示を出す
- 追加失敗（API）: モーダル内に分かる表示を出す

## Non-Goals

- API仕様の変更は行わない
- 学習項目のデータ内容（フィールド）や学習スケジュール算出ロジックは変更しない
