# Quickstart: 学習項目追加モーダル化

**Branch**: 003-item-add-modal  
**Date**: 2026-03-02

このドキュメントは、学習項目追加をモーダル化した動作をローカルで検証するための手順をまとめる。

---

## Prerequisites

- Node.js（LTS推奨）
- npm
- バックエンドAPIが起動できること

---

## Run

### Backend

- 既存の起動手順に従う（例: [../001-forgetting-curve-manager/quickstart.md](../001-forgetting-curve-manager/quickstart.md)）

### Frontend

- `cd frontend`
- `npm install`
- `npm run dev`

---

## Verification Checklist

### US1（右上ボタン→モーダル→追加→一覧反映）

- [ ] 一覧領域の右上に「新規」ボタンが表示される
- [ ] 「新規」ボタン押下で学習項目追加モーダルが開く
- [ ] タイトル等を入力して「追加」を押すと、追加処理が実行される
- [ ] 追加成功時にモーダルが閉じ、一覧に追加された項目が表示される
- [ ] 必須項目未入力で「追加」を押した場合、モーダル内に入力不備が分かる表示が出て閉じない

### US2（キャンセル/ESC/背景クリックで閉じてクリア）

- [ ] 入力途中に「キャンセル」を押すとモーダルが閉じ、再度開くと入力が空である
- [ ] 入力途中に ESC を押すとモーダルが閉じ、再度開くと入力が空である
- [ ] 入力途中に 背景クリック をするとモーダルが閉じ、再度開くと入力が空である

### Error / Duplicate Submit

- [ ] 追加処理中に「追加」を連打しても重複送信されない（例: 追加ボタンが disabled になる）
- [ ] 追加失敗時にモーダル内に失敗表示が出て、モーダルが閉じない
