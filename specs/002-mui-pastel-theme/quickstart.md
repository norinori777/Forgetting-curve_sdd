# Quickstart: パステルテーマ適用（MUI不使用）

**Branch**: 002-mui-pastel-theme  
**Date**: 2026-02-26

このドキュメントは、Tailwindでのパステルテーマ適用をローカルで検証するための手順をまとめる。

---

## Prerequisites

- Node.js（LTS推奨）
- npm

---

## Setup

### Frontend

- 依存関係インストール
  - `cd frontend`
  - `npm install`

- 外部UIコンポーネントライブラリは導入しない（Material UI（MUI）は使用しない）

---

## Run

- 事前にバックエンドAPIが起動していることを確認
  - 既存の起動手順に従う（例: [../001-forgetting-curve-manager/quickstart.md](../001-forgetting-curve-manager/quickstart.md)）

- フロント開発サーバ起動
  - `cd frontend`
  - `npm run dev`

---

## Verification Checklist

このチェックリストは、T012/T016/T020 の手動検証に対応する。

### US1（追加/一覧/削除 + 見た目統一）

- [x] 画面が表示できる（学習項目ページが開ける）
- [x] 追加フォームの入力欄（タイトル/内容/タグ）が同一の見た目（余白/角丸/枠線/フォーカス）になっている
- [x] 「追加」ボタンがテーマに沿った見た目で、無効状態が分かる
- [x] タイトルを入力して「追加」すると、一覧に新しい行が増える
- [x] 一覧の見出し/セル/タグがテーマに沿った見た目で統一されている
- [x] 一覧の各行に「削除」ボタンがあり、押すと削除される
- [x] 削除中は対象行の「削除」ボタンが無効になり、状態が表示される（例: "削除中..."）

### 重要状態（高コントラスト）

- [ ] 取得失敗時の表示が、通常表示と明確に区別できる（枠/背景/文字色）
- [ ] 追加失敗時の表示が、通常表示と明確に区別できる（枠/背景/文字色）
- [ ] 削除失敗時の表示が、通常表示と明確に区別できる（枠/背景/文字色）
- [ ] 期限切れ（"期限切れ" 表示と日付強調）が背景に埋もれず判別できる

### US2（レスポンシブ）

- [x] スマホ幅でもフォームの操作ができる（入力/ボタンが画面からはみ出さない）
- [x] スマホ幅でも一覧が操作不能にならない（横スクロールでき、ボタンが押せる）
- [x] タブレット幅/PC幅でも情報が詰まりすぎず、見出し/フォーム/一覧が判別できる
