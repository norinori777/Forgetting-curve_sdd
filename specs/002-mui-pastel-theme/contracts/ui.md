# Contract: UI Theme / Component Usage（パステルテーマ適用・Tailwind統一）

**Branch**: 002-mui-pastel-theme  
**Date**: 2026-02-26

本ドキュメントは、UIの一貫性を保つための「UI契約（テーマとコンポーネント利用方針）」を定義する。

---

## Scope

- 対象: フロントエンドの全ページ（将来増えるページも含む）
- 目的: TailwindでUIコンポーネントの見た目を統一し、パステルカラー基調のテーマを一貫適用する

## Theme Rules

- パステルカラー基調を採用する（淡い背景色 + 読みやすいテキスト）
- エラー/重要状態は通常状態と明確に区別できる（背景に埋もれない）。高コントラスト色を許容する
- 重要テキストはWCAG AAの目安（通常文字 4.5:1、太字/大文字 3:1）を満たす

## Component Rules

- Material UI（MUI）は使用しない
- 外部UIコンポーネントライブラリは導入しない
- ボタン/入力/テーブル/アラート等の主要要素は、Tailwindの共通クラス（`@layer components` 等）で見た目を統一する

## Validation Display Rules

- フォームのバリデーションは、入力の直下にエラーテキストを表示してユーザーが判別できるようにする
- レイアウトが揺れる場合は、エラー表示領域の高さを確保してよい

## Accessibility Rules (Minimum)

- 重要な情報（エラー/期限切れ等）は、色だけでなく文言でも判別できる
- パステル背景に対してテキストの視認性が確保される（コントラスト不足を避ける）
