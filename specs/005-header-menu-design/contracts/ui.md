# UI Contract: ヘッダーメニュー（タイトル左寄せ + デザイン画像指定）

## 対象

- アプリ全画面に常時表示されるヘッダー
- ヘッダー内の「左端ブランド（アイコン+タイトル）」と「メニュー3項目」の配置・振る舞い

## 表示要件

- ヘッダーはアプリ内の全画面（全ルート）で表示されること
- ヘッダー左端に以下を表示すること
  - アイコン: テキストのモノグラム `FC`
  - アプリタイトル: `Forgetting-curve`
- ヘッダーに以下3つのメニューを表示すること（表示順は左から固定）
  - 復習
  - 集計
  - 設定（プリセット）

## 振る舞い要件

- 各メニューは1回の操作で対応画面へ遷移できること
  - 復習 → `/review`
  - 集計 → `/stats`
  - 設定（プリセット） → `/presets`
- 現在表示中ページに対応するメニュー項目はアクティブ表示で区別できること
- 左端の「アイコン+アプリタイトル」はクリック（タップ）しても画面遷移しないこと（表示のみ）

## レイアウト要件

- 幅 1280px 程度の表示条件では、メニュー3項目は横並びかつ等間隔に配置されること
- 幅 375px 程度の表示条件では、ヘッダーは2段に折り返して表示されること
  - 1段目: 左端に「アイコン+アプリタイトル」
  - 2段目: メニュー（3項目）
- 幅 375px 程度でも、3メニュー項目は欠落せず常に操作可能であること

## 右端（画面右側）の扱い

- 右端にはブランド要素（アイコン/アプリタイトル）を表示しないこと（左端に集約）

## 例外/フォールバック

- アイコン表示ができない場合でも、アプリタイトルとメニューの表示・操作は維持されること
- アプリタイトルが長い場合でも、タイトル表示が完全に欠落しないこと（省略表示は許容）
