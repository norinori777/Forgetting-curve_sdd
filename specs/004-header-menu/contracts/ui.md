# UI Contract: ヘッダーメニュー

## 対象

- アプリ全画面に常時表示されるヘッダーメニュー

## 表示要件

- 画面上部に固定的に表示されること（スクロール追従の要否は本スコープ外。少なくとも各画面の先頭に表示されること）
- 右端に「アイコン」と「アプリ名」を表示すること
- アプリ名の左側に、以下3つのメニューを横並びで表示すること
  - 復習
  - 集計
  - 設定（プリセット）
- メニュー表示順は左から `復習 → 集計 → 設定（プリセット）`

## 振る舞い要件

- 各メニューは1回の操作で対応画面へ遷移できること
  - 復習 → `/review`
  - 集計 → `/stats`
  - 設定（プリセット） → `/presets`
- 現在表示中ページに対応するメニュー項目はアクティブ表示で区別できること

## レイアウト要件

- デスクトップ相当の表示幅では、3メニューは横並びで「等間隔」に配置されること
- 画面幅が狭い場合は2段に折り返すこと
  - 1段目: メニュー（3項目）
  - 2段目: アイコン + アプリ名（右寄せ）
- 狭い画面でもアクティブ表示が判別可能であること

## 例外/フォールバック

- アイコンが表示できない場合でも、アプリ名とメニューの表示・操作は維持されること
